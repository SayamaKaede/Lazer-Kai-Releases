# Lazer-Kai

osu! および ppy とは関係ありません。不具合が発生しても osu! 側に問い合わせないでください。

[osu!lazer](https://github.com/ppy/osu) のフォークです。マッピングを楽にすることだけを基準に、エディターへ機能を追加しています。

ポータブル形式で、譜面・設定・スコアはフォルダの中に保存されます。本家の osu!lazer とは別のデータを使うので、どちらも両立して使用できます。

## インストール

[Releases](https://github.com/SayamaKaede/Lazer-Kai-Releases/releases) から `LazerKai-win-Portable.zip` をダウンロードし、好きな場所に展開して `Lazer-Kai.exe` を実行してください。

## 更新

自動で更新されます。通知をクリックしてダウンロードが終了後、再起動すると適用されます。

## 再配布について

配布は [Releases](https://github.com/SayamaKaede/Lazer-Kai-Releases/releases) だけで行っています。転載や再配布はなるべくしないでください。外部での宣伝もしないでください。

古いバージョンが出回ると、修正済みの不具合の報告が届いたり、更新の通知が表示されない状態の人が発生したりします。人に渡すときは、このページを教えてください。
